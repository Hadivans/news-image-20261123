Sum up 23 November's world news in one image. A deterministic Python program (stdlib + Pillow, fonts bundled in `fonts/`) draws a newspaper front page — "THE WORLD — Monday, 23 November 2026" — with six verified real stories: the COP31 climate talks collapsing in Antalya, Democrats clinching 258 US House seats, Mexico's capture of "El Chapo Isidro", the deadly candy-factory fire in Indonesia, Wall Street's AI sell-off, and Alcaraz winning the ATP Finals. Every story was verified against Reuters, Associated Press and Xinhua reports published 21–23 November 2026. The program runs with no network and writes byte-identical output on every run.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024, under 1 MiB) to `/output/entry.png`.
